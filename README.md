# element-atelier

**원소 하나가 나라가 되고, 물질이 가문이 되고, 물건이 주민이 된다.**

주기율표 118원소가 저마다 한 나라다. 그 원소로 된 물질(강철·녹·물·소금)이 가문이고, 그 물질과 닿은 물건(검·못·물병·금화)이 주민이다.
나라의 근본·가문주·주민이 **판타지 · 스팀펑크 · 메카** 세 세계에서 각각 한 사람으로 선다. 현대는 일상컷이 맡는다.

- 화면: [원소 공방](index.html) — 주기율표 → 나라(궤도 · 목록) → 가문 → 한 장으로 들어가는 한 화면, 합성 · 화풍 · 프롬프트는 구석의 도구 상자. GitHub Pages 로 연다. 뼈대: [DESIGN.md](DESIGN.md)
- 기획: [docs/ELEMENT_CONCEPT.md](docs/ELEMENT_CONCEPT.md)
- 설계표: [data/element-design.json](data/element-design.json) — `python3 tools/element-design.py check`
- 그림 규칙: [IMAGE_RULES.md](IMAGE_RULES.md) · 작업 지침: [AGENTS.md](AGENTS.md) · 가져온 것: [docs/PORT_NOTES.md](docs/PORT_NOTES.md)
- 그림은 이 저장소에 두지 않는다 — [element-atelier-img](https://github.com/polos0117/element-atelier-img)

자료 · 생성기 몫은 game-atelier 에서 가져왔고, 화면 뼈대는 이 공방 것이다. 읽히는 글자·숫자는 그리지 않는다. 비상업 팬작업이다.
